# 縮放Adobe AI代理程式：Audience Agent和Data Insights Agent

瞭解Audience Agent和Data Insights Agent如何將Ad Hoc AI使用轉換為可重複、可測量的工作流程。 此活動示範團隊如何加速細分、對象管理、行銷活動分析和效能診斷，同時建立成功擴展所需的治理和測量實務。

>[!VIDEO](https://video.tv.adobe.com/v/3496958/?learn=on&enablevpops)

## 學習目標

在此會議中，您將探索：

- 在Adobe Experience Platform和Customer Journey Analytics中縮放AI代理程式背後的基本概念。
- Audience Agent和Data Insights Agent的詳細功能，包括主要使用案例和實際應用程式。
- 這些代理程式如何共同運作以偵測問題、調整定位和評估影響。
- 從臨機AI提示轉換為結構化、可重複的工作流程的策略。

## 目標客群

此活動專為下列用途而設計：

- 使用Adobe Customer Journey Analytics和Adobe Experience Platform的開發人員和使用者。
- 初等和中級專業人員，希望加深對擴展AI功能的瞭解。

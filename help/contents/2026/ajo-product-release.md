# AJO產品發行工作階段

探索Adobe Journey Optimizer (AJO)的最新更新，這些更新可讓企業提供個人化、有效率且具影響力的客戶體驗。 本課程著重於新發行的功能，旨在實現個人化目標、最佳化營運及提升團隊生產力。

>[!VIDEO](https://video.tv.adobe.com/v/3491221/?learn=on&enablevpops)

## 重點提要

- **傑出的功能：**&#x200B;瞭解AJO在客戶歷程協調方面有何成就。
- **新功能：**&#x200B;探索資料集查詢、內容決策和歷程路徑最佳化等功能。
- **管道創新：**&#x200B;瞭解WhatsApp、網頁推播和iOS即時活動等新興管道。
- **生產力增強功能：**&#x200B;探索可簡化內容建立和加速傳遞程式的工具。

這些更新可協助企業運用進階決策、有效實驗，以及橫跨多個管道觸及客戶，進而促進更多轉換並提高營運效率。

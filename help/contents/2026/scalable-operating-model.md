# 控管無障礙：在Adobe Workfront中建立可擴充的行銷工作運作模型

隨著行銷團隊在各個地區、品牌和代理商之間的成長，管理工作也變得越來越複雜。 新增更多工具通常無法解決根問題。 真正的解決方案在於實作健全的作業模型，清楚定義擁有權、工作攝入流程和容量規劃。

在這場會議中加入我們，探索企業行銷團隊如何運用Adobe Workfront建立輕量型的控管、標準化工作流程、自信地管理團隊容量，並在分散的組織中提供即時透明度。 您離開時將採取實用策略，將營運混亂轉換為可擴充、有效率的模式，讓您的團隊能夠運作。

>[!VIDEO](https://video.tv.adobe.com/v/3497156/?learn=on&enablevpops)

## 重點提要

1. **為您的組織選擇正確的作業模式**\
   決定集中式、同盟式和軸輻式模式，並探索為何軸輻式方式通常最適合大型、多品牌或多區域團隊使用。

2. **啟用而非阻礙的設計治理**\
   瞭解如何在Workfront中建立決定權利、請求錄取和核准路由，以在不減慢團隊速度的情況下實施標準。 瞭解維持營運健全狀態的治理委員會步調的重要性。

3. **標準化工作流程以保持一致性**\
   使用請求佇列、自訂表單、範本、藍圖及校訂工作流程，以確保跨團隊的簡報、專案和稽核的一致性，減少低效問題。

4. **有效管理容量**\
   利用工作負載平衡器和情境規劃器等資源規劃工具，根據證據做出容量決策，確保現實的承諾。

5. **提升主管的營運透明度**\
   建立控制面板、產品組合檢視並調整目標，為主管提供輸送量、瓶頸和優先順序進度的即時深入分析。

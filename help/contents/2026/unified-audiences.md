# 解鎖AEP中的同盟對象構成(FAC)：從資料獨立單位到統一對象

探索Adobe Experience Platform同盟受眾構成(FAC)如何劃分資料獨立單位，以提供統一且可操作的受眾。 FAC可讓組織直接從現有的資料來源啟用對象，而不需移動或複製資料。 此方法尊重資料控管和隱私權，同時促進即時客戶參與。

>[!VIDEO](https://video.tv.adobe.com/v/3486505/?learn=on&enablevpops)

本課程說明企業資料倉儲與Adobe Real-Time CDP和Adobe Journey Optimizer的整合，說明企業如何整合客戶設定檔及豐富受眾區段。 FAC支援受眾建立、擴充和設定檔增強功能，可跨頻道提供個人化體驗。

影片內容已內嵌於下方，展示FAC的逐步實作，從資料庫設定到對象啟用。 此會議著重說明實用程式，並強調業務成果，例如改善客戶體驗和簡化的資料操作。

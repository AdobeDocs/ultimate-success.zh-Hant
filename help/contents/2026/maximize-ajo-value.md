# 建立客戶體驗策略以充份發揮AJO的價值

本會議探討如何透過錨定明確的客戶體驗策略中的啟動、將其轉換為可衡量的使用案例，並透過協調的跨職能流程執行，來最大化來自Adobe Journey Optimizer的價值。 主要優點包括提高策略清晰度、更符合業務優先順序、更具影響力的個人化、提升營運效率，以及提供可衡量一致客戶成果的可擴充架構。

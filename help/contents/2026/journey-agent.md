# 縮放Adobe代理程式：Journey Agent

探索Journey Agent如何將自然語言工作流程與人類監督相結合，以加速歷程建立、分析和最佳化。 在啟用之前，取得控管、許可權、建議透明度、同意和審查的實際見解。

>[!VIDEO](https://video.tv.adobe.com/v/3496957/?learn=on&enablevpops)

## 學習目標

- Journey Agent如何使用自然語言提示簡化歷程建立。
- 在AI工作流程中治理和人力監督的重要性。
- 最佳化客戶歷程的實用策略。
- 深入分析Adobe支援Journey Agent的AI架構。

## 目標客群

此活動專為下列用途而設計：
- 管理員
- 導線
- 使用者

適合所有體驗層級的個人，從初學者到經驗豐富者。

## 日程

1. **Journey Agent簡介**
   - AI導向工作流程概觀。
   - 人在歷程最佳化中的角色。
2. **Adobe的AI架構**
   - 資料基礎：AEP和RT-CDP。
   - 協調層：Agent Orchestrator。
   - 專業代理概述。
3. **深入探討Journey Agent**
   - 歷程建立、分析和最佳化。
   - 實用使用案例和範例。
4. **採用與整備**
   - 技術必備條件。
   - 組織整備。
   - 實作的策略規劃。
5. **治理與許可權**
   - 確保法規遵循與品牌標準。
   - AI決策的透明度。
6. **後續步驟與問答**
   - 分階段採用方法。
   - 適用於組織的立即動作。

# 從Adobe Analytics移轉至Customer Journey Analytics：您的移轉藍圖

瞭解確保成功的關鍵步驟，為自信地從Adobe Analytics移轉至Customer Journey Analytics (CJA)做好準備。 此活動提供完整的藍圖，引導您完成轉換，涵蓋從基礎知識到進階移轉整備的所有內容。

>[!VIDEO](https://video.tv.adobe.com/v/3496954/?learn=on&enablevpops)

## 學習目標

- **瞭解CJA**：瞭解Customer Journey Analytics是什麼、其運作方式，以及它與Adobe Analytics有何不同。
- **身分識別與拼接**：深入瞭解身分識別策略與拼接的概念，確保客戶資料的統一檢視。
- **移轉整備**：探索必要的準備步驟，包括變數對齊、身分策略和結構描述設定。
- **避免陷阱**：瞭解常見的移轉挑戰，以及如何克服這些挑戰。
- **最佳實務**：深入瞭解資料驗證、回填程式和控管，以順利轉換。
- **實用藍圖**：為您的移轉歷程提供明確、可行的計畫，讓您順利離開。

## 目標對象

此活動專為下列用途而設計：

- **管理員**：負責監督移轉的技術層面。
- **領導者**：專注於策略決策和資源配置。
- **使用者**：移轉後會使用CJA的一般使用者。

## 日程

1. **CJA簡介**： Customer Journey Analytics及其功能的概述。
2. **身分策略與拼接**：
   - 瞭解身分欄位及其重要性。
   - 探索拼接方法：欄位型和圖表型。
3. **移轉準備程度**：
   - 準備資料和對齊變數。
   - 從工作階段型分析轉換成CJA的報告時間處理。
   - 設定方案和資料檢視。
4. **避免常見陷阱**：
   - 解決弱身份識別策略的問題。
   - 疑難排解變數未對齊和資料差異。
5. **正在執行移轉**：
   - 使用工具和驗證資料的逐步指南。
   - 處理歷史資料回填。
6. **問答會**：解決您的特定問題和顧慮。

加入我們，獲得成功轉換至Customer Journey Analytics所需的知識和信心。 到活動結束時，您將具備開始規劃移轉所需的工具、見解和最佳實務。

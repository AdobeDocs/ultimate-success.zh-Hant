# 快速啟動您的整合： Campaign REST API快速入門

Campaign REST API透過橋接與行銷或服務動作的參與時刻，提供簡化方式來建立有價值的客戶互動。 此課程是Ultimate Success系列的一部分，旨在協助您有效瞭解及利用這些API。

## 重點提要

- 瞭解如何將使用案例轉換為可測試的小型整合故事。
- 瞭解API在哪裡建立值，以及這些可能不正確的工具。
- 深入瞭解如何製作請求圖形、設定護欄及建立生產路徑。

## 概覽

Adobe Campaign REST API不僅僅是工具；它們也是建立立即和個人化客戶互動的閘道。 這些API允許您：

- 根據客戶時刻觸發特定動作，例如傳送確認電子郵件或更新使用者偏好設定。
- 實現與其他應用程式的緊密整合，包括Adobe和外部系統。
- 支援低延遲、事件導向的使用案例，例如捨棄購物車通知、歡迎電子郵件和交易確認。

## 日程

1. **業務概觀：**
   - REST API的策略概念。
   - 識別API使用的客戶時刻。
2. **技術深入分析：**
   - 設定和驗證API端點。
   - 設定IMS驗證和開發人員控制檯專案。
   - 瞭解端點選取和裝載自訂。
3. **示範：**
   - 在Adobe Campaign中設定事件型別和範本。
   - 將Postman用於SOAP和REST API呼叫。
   - API呼叫及其結果的實用範例。
